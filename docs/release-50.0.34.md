# BWS 50.0.34

v50 is the single supported edition. Startup ignores legacy preferences and no longer offers an edition switch. Legacy entry links redirect to v50. Website builds include only the current studio bundle and the legacy redirect, not the retired editor.

Workspace recovery and pending handoff backups remain supported. Fireplace and Minecraft remain optional plugins.

Includes accumulated v50 plugin-loader, Geometry Nodes bridge, Animator layout and axis-view improvements through 50.0.33. Canonical source and browser bundle synchronized; no additional tests run for this release.
