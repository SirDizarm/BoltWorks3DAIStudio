        Edge Bevel
        

          
        

        
        
Choose Edge, select one visible crease, then apply. Flat triangulation diagonals are ignored.

      

      

        Corner Bevel
        

          
          
          
        

        
        
        
Standard creates a real corner chamfer that remains OBJ-exportable. Minecraft rebuilds a box on a 16×16×16 voxel grid and removes stepped pixels from the selected corner.

      

      

        Subdivide Surface
        

          
        

        
        
Level 1 creates 4 triangles from each selected triangle. Level 2 creates 16. Neighboring edges are split automatically so the mesh stays closed while shaping.

      

      

        Loop Cut / Ring Cut
        

          
          
          
        

        
        
One cut uses Position %. Multiple cuts are evenly spaced. New ring edges stay selected for Move or Edge Slide.

      

      

        Knife / Plane Cut
        

          
          
        

        
        
Knife: click two points on the same mesh. The current camera guides a straight cutting plane; turn the Knife button off to return to normal selection.

        

          
          
          
        

        
        
        
Keep Both Sides inserts real topology without removing geometry. Positive or Negative removes one side; Cap closes the new opening with planar UVs. Existing texture coordinates and materials are retained.

      

      

        Bridge Edge Loops
        
        
Choose Edge. Select one boundary edge on each of two open loops with Shift/Ctrl, then bridge them. Both loops must belong to the same mesh and currently need the same number of vertices. Existing texture coordinates are extended across the new quad strip.

      

      

        Normals
        

          
          
        

        
Recalculate Outside repairs inconsistent triangle direction across the selected mesh and points closed components outward. Flip Selected Faces reverses only the current Triangle or Whole Face selection. UVs, colors, materials, and topology are retained.

      

      

        Find and Repair Holes
        
Select one editable mesh, then scan for true open boundary loops.

        

          
        

        

          
          
          
          
          
          
        

        
Repairs are added to the same mesh with controlled planar UVs and the surrounding material. Projection supplies the initial mapping. After repairing, select the new surface and use Selected Face UV below to rotate or flip its texture. Twisted, self-intersecting, degenerate, or non-manifold results are refused without changing the model.

      

      

        Non-manifold Check
        
Select one editable mesh, then inspect its topology.

        

          
          
          
          
          
        

        
Reports open boundary edges, edges shared by more than two triangles, disconnected vertex fans, duplicate triangles, degenerate triangles, and inconsistent winding. This diagnostic never changes the model.

      

      

        Remove Doubles
        
Select one editable mesh, then analyze nearby overlapping vertices.

        

          
        

        

          
          
        

        
Only separate positions closer than Tolerance are merged; ordinary non-indexed corners already sharing the exact same position are ignored. UVs, colors, skin data, and materials stay attached per triangle corner. A result that opens a closed mesh or creates a non-manifold edge is refused.

      

      

        Mesh Statistics
        
Select one editable mesh, then calculate a read-only geometry report.

        

          
          
        

        
No report yet.

        
Reports dimensions, triangles, GPU and welded vertices, edges, topology health, surface area, closed volume, UV/material data, and approximate geometry memory. Statistics never change geometry or consume Undo.

      

      

        Protected Decimate
        
Select one editable mesh, then analyze a protected triangle reduction.

        

          
          
        

        
        
        
        

          
          
        

        
Short internal edges are collapsed first. Open borders, sharp silhouette details, UV seams, and material borders can be protected. Analysis never changes the model. Apply retains per-corner texture and material data, refuses unsafe topology, and supports Undo.

      

      

        LOD Generator
        
Select one editable mesh, then analyze a protected LOD set.

        

          
          
          
          
        

        
        
        
        
        

          
          
        

        
LOD0 is always the unchanged source model. LOD1–LOD3 are separate models in one named scene group, retain texture/material data, and are hidden by default to prevent overlap. Toggle Hide in the scene tree to inspect one level at a time. One Undo removes the complete generated set.

      

      

        UV Unwrap / Texture Atlas
        
Select one editable mesh, then analyze a smart UV layout.

        

          
          
          
        

        

          
          
          
        

        

          
        

        
1 PNG selected: select one textured mesh to make it ready.

        
        
Original Texture exports the unchanged source image shown in Mesh Details, without UV islands. Analyze is read-only. Apply changes only UV coordinates. Bake remaps the current texture into a separate atlas so the visible surface stays aligned. UV Guide exports colored triangle and island outlines for external painting. Apply and Bake support Undo.

      

      

        Selected Face UV
        

          
          
          
          
        

        
Choose Triangle or Whole Face and select the repaired surface—or any textured surface—before rotating or flipping its UVs. Geometry, material, and neighboring faces stay unchanged. Each action can be undone.

      

      

        Edge Slide
        

          
          
        

        
        
Choose Edge or create a Loop Cut. Positive and negative values slide in opposite directions. Auto remembers the Loop Cut direction and otherwise follows the strongest neighboring rail.

      

      

        Scale Selected Surface
        

          
          
        

        
        
Scales only the selected surface around its own center. Uniform keeps a flat face in its plane; X, Y, or Z changes one world-space dimension. Texture coordinates and selection are retained.

      

      

        Smooth / Relax Vertices
        

          
          
          
        

        
        
        
Choose Vertex and select the points to edit. Relax Surface moves displaced points toward their connected neighboring surface and keeps the center of multi-point selections stable. Smooth Shape can also round the silhouette. UV coordinates and closed topology are retained.

      

      

        Weld Vertices
        

          
        

        
        
Choose Vertex and select at least two vertices with Shift/Ctrl. UVs and materials are preserved, redundant triangles are removed, and the result stays selected.

      

      

        Dissolve Edge or Vertex
        
        
Edge: select a flat internal modeling edge. Vertex: select an internal manifold vertex on one continuous material surface. Boundary edges, UV seams, and invalid topology are protected. The viewport reports whether Dissolve completed or why it was blocked.
