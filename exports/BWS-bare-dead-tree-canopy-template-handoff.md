# Bare Dead Tree — Canopy Template

This asset is intentionally leafless. It matches the supplied dead-tree reference with a tapered, lightly S-curved trunk, a stronger lower-left silhouette, and thin uneven twig forks.

## Editable structure

- One group: `Bare Dead Tree — Canopy Template`
- 21 separate editable objects: 4 trunk sections and 17 branch/twig sections
- +Y is up; the base is on the XZ ground plane
- Dark, very rough wood colors are assigned per segment so the branch hierarchy remains readable before a texture pass

## Canopy plan

Use the outer twig ends as foliage anchors rather than covering the whole trunk. Good first canopy zones are the left middle crown around `[-1.1, 5.6, 0]`, the right crown around `[1.7, 5.2, 0]`, and the upper crown around `[0.2, 7.5, 0]`.

Keep the main S-curve, lower left branch, and several outer twigs visible when adding foliage; those give the tree its silhouette.

The branch base was reloaded and checked again before the canopy version was made. No separate parts were flying: every limb endpoint overlaps its trunk or parent limb, and the flared base remains above Y=0.
