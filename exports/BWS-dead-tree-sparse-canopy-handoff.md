# Dead Tree — Sparse Canopy

Derived from `BWS-bare-dead-tree-canopy-template.modelerproj` after checking all 21 base parts for disconnected or flying geometry. No branch parts required repositioning; their endpoints overlap parent segments and the base clears the ground plane.

The canopy is a second editable group, `Dead Tree — Sparse Leaf Canopy`, made of nine low-poly faceted leaf clusters. It deliberately keeps the trunk and outer twigs visible.

For the next canopy pass, grow the foliage around the existing cluster anchors instead of covering the tree uniformly. Keep the sparse dead-tree silhouette readable.
