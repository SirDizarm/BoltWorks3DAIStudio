# Scene workspace - v49.64.63

Scene Studio is now a named Workspace choice beside General 3D and Minecraft. Removed the Geometry Nodes-area launch button. The scene header includes its own workspace selector; Back to Model switches to General 3D. Switching workspaces preserves the in-memory scene and leaves model geometry unchanged. Workspace preference is remembered, while scene data still requires Save scene.

Sources: minecraft.js, scene-studio.js, index.html. Synchronized browser bundle: studio-v49.64.63.js. No browser testing performed.
