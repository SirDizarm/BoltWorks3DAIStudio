# Regenerate centered - v49.64.28

The Geometry Nodes toolbar now has Regenerate centered beside Build / Update Geometry, in both the sidebar and detached window. It regenerates the active graph, computes the combined world bounds of its output after Output Transform, centers the result on X/Z, and translates its lowest point to Y=0. Multiple wall copies are centered as one assembly. Their relative spacing and textures are unchanged.

Centering applies to any geometry generated by the active graph, not an unrelated selected/baked/imported scene object. Rebuild replaces that graph's generated geometry as usual; preserve manual edits by baking or saving before regeneration. Other graphs and unrelated scene objects are not moved.

The graph stores centerOutput=true so subsequent Build and Add copy right operations remain centered. Centering overrides net output translation while retaining relative offsets and rotation/scale. Undo is recorded before enabling and rebuilding. Bounds are computed in world space and positions converted back to parent space.

Source app/modules/geometry-nodes.js and index.html updated with loaded studio-v49.64.28.js. Bundle generated; no live editor centering tests run.
