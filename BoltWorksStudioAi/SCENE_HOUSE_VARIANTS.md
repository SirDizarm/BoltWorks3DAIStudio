# Scene variants - v49.64.64

Scene Studio now stores up to eight static house variants. Add current model appends rather than replacing the library. Generate variants from house nodes builds up to six independent house geometries from the active House Layout recipe with differing widths, depths, 1-3 storeys, masonry inset/courses and material defaults. Connected palette inputs retain their precedence. Main model geometry is unchanged. Scene generation instances each variant separately. Save scene v2 includes all library entries; v1 imports remain supported.

Winding village roads are sampled sinusoidal lanes with cross streets. Houses orient toward their adjacent road; rotation jitter is additional. Trees and rocks avoid both roads and entrance paths. Grid remains available. This is not arbitrary curved-road authoring, L-shaped architecture, terrain, rivers or photographic rendering. No browser validation performed.

Source scene-studio.js synchronized with studio-v49.64.64.js.
