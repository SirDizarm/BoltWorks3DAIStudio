# Automatic node nature - v49.64.69

Generate town now evaluates real tree and rock node recipes automatically when requested scatter has no loaded source. Empty selectors create editable Scene broadleaf tree and Scene fieldstone graphs in the project. Selected graph recipes can be evaluated without a prior modeling-workspace build. Uses the same buildGeometryNodeTree evaluator in isolated preview mode; no scene objects are removed/added, the active graph is unchanged, and previews do not write build history. Starter recipes are saved in the project graph library. Use node output regenerates a source after editing its recipe.

No cone-tree or polyhedron placeholder path is used. Standard canopy nodes themselves legitimately use low-poly foliage clusters. The scene instances the evaluated node asset with seed-based transforms.

Sources geometry-nodes.js and scene-studio.js synchronized with studio-v49.64.69.js. No live validation performed.
