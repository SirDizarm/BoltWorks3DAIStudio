# Barrel roof tiles - v49.64.40

The existing curved roof style now generates tapered barrel covers with concave half-channels at column boundaries. Tiles have wall thickness, end rims and raised down-slope lips. Courses extend downhill for overlapping placement, stopping at eaves; chimney cutouts are applied after extending the overlap.

The reference photographs inform geometry only. No watermarked photograph is used as a texture. Existing roof colors/material connections remain in effect; photographed weathering is not reproduced by this geometry change. Existing .bwnc files using curved automatically use this replacement on rebuild. Clay, slate and shingles remain unchanged.

Source geometry-building.js synchronized with studio-v49.64.40.js and versioned index. Build only; no live visual validation performed.
