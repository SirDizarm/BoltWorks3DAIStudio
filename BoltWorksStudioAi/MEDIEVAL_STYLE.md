# Medieval style first pass - v49.64.42

New Medieval Style attachment: full-height stone ground floor, wraparound corner stones, gable timber divisions and braces, diamond window leading, minimum roof pitch. Stone ground floor uses existing wall opening subtraction. Gable timber is partitioned from infill and prior strips rather than overlaying coplanar boxes.

New scalloped roof style: rounded lower tile ends with sloping overlap lips. Geometry only: no thatch, weathering textures or photo textures. These features work downstream of House Layout, including House Batch. Existing graphs remain unchanged unless Medieval Style is added. Steep pitch is explicitly configurable.

Preset GeneratedAssets/Medieval/medieval-gabled-house.bwnc demonstrates the new node. This remains a rectangular shell, not a recreation of all references. Joined L/T wings, dormer openings, upper-storey jetties, arched doors, revised stair halls and texture-library nodes remain outstanding. No automatic furniture/room solver.

Sources geometry-building.js and geometry-building-details.js synchronized with studio-v49.64.42.js. Build only, no live model inspection performed.
